# Zecpath AI System

Zecpath is an AI-powered hiring platform designed to automate
different stages of the hiring lifecycle.

## Project Structure

- data/ - Data files and sample datasets
- parsers/ - Resume and document parsing
- ats_engine/ - AI-based resume screening and scoring
- screening_ai/ - AI candidate screening
- interview_ai/ - AI interview functionality
- scoring/ - Candidate scoring and decision logic
- utils/ - Common utilities such as logging
- tests/ - Test scripts

## Technology

- Python
- AI/NLP models
- PostgreSQL / MongoDB
- REST APIs
